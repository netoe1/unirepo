# **Trabalho Prático 1 – TP1**

## **Algoritmos e Classificação de Dados (ACD)**

### **1\. Objetivo do trabalho**

O TP1 consiste em um **projeto prático de programação, experimentação, análise e apresentação de resultados** envolvendo algoritmos de ordenação estudados no componente de Algoritmos e Classificação de Dados.

O trabalho tem como objetivos:

* implementar diferentes algoritmos de ordenação em Java;  
* verificar experimentalmente a corretude das implementações;  
* planejar e executar experimentos para avaliar o desempenho dos algoritmos;  
* coletar, organizar e analisar os tempos de execução;  
* comparar os resultados experimentais com a análise teórica de complexidade dos algoritmos;  
* identificar características da implementação e das entradas que possam influenciar o desempenho;  
* apresentar e discutir os resultados obtidos em um documento técnico e em uma apresentação.

O trabalho poderá ser realizado em **duplas** e, excepcionalmente, em **trios**. O TP1 terá peso de **16% na média do componente de ACD** e será computado como atividade EaD, com carga horária vinculada de **5 horas**.

O trabalho deverá ser apresentado pelo(s) discente(s) ao docente e, preferencialmente, também à turma, conforme o cronograma do componente.

# **2\. Algoritmos a serem implementados**

Cada grupo deverá implementar, em Java, os seguintes algoritmos:

### **Algoritmos baseados em comparação** 

* Bubble Sort;  
* Insertion Sort;  
* Selection Sort;  
* Shell Sort;  
* Heap Sort;  
* Merge Sort;  
* Quick Sort.

### **Algoritmos de tempo linear**

* Counting Sort;  
* Radix Sort;  
* Bucket Sort.

Os algoritmos deverão ser implementados pelos próprios grupos, não sendo permitido utilizar diretamente métodos de ordenação prontos da API Java para substituir as implementações solicitadas.

Para os algoritmos baseados em comparação, recomenda-se a utilização da interface `Comparable` da API Java, permitindo que os métodos trabalhem com diferentes tipos de dados comparáveis.

Por exemplo:

`public class Ordenadores {`

    `public static <T extends Comparable<T>>`  
    `void quicksort(T[] a, int lo, int hi) {`  
        `// ...`  
    `}`

    `public static <T extends Comparable<T>>`  
    `void heapsort(T[] a, int n) {`  
        `// ...`  
    `}`

    `// demais algoritmos e métodos auxiliares`  
`}`

Cada método deverá possuir os parâmetros necessários ao seu funcionamento. Métodos auxiliares poderão ser utilizados quando necessários.

Os algoritmos Counting Sort, Radix Sort e Bucket Sort possuem requisitos específicos sobre os dados de entrada e, portanto, deverão ser tratados considerando suas características próprias.

# **3\. Etapas do trabalho**

## **Etapa 1 – Implementação e verificação dos algoritmos**

Inicialmente, cada grupo deverá implementar e testar os dez algoritmos de ordenação.

Além da implementação, deverão ser preparados **vetores pequenos de teste**, entre 10 e 15 elementos, para verificar o comportamento dos algoritmos em diferentes situações.

Recomenda-se utilizar, no mínimo, os seguintes casos:

1. elementos em ordem crescente;  
2. elementos em ordem decrescente;  
3. elementos em ordem aleatória;  
4. elementos com várias ocorrências repetidas.

Os vetores deverão possuir tamanhos diferentes, incluindo tamanhos pares e ímpares.

Esses testes não têm como objetivo provar formalmente a corretude dos algoritmos. Seu propósito é permitir uma verificação prática inicial das implementações antes da realização dos experimentos de desempenho.

## **Etapa 2 – Preparação dos dados de entrada**

Os experimentos deverão utilizar vetores com diferentes características.

### **2.1 Ordem dos elementos**

Deverão ser considerados, sempre que aplicável:

* elementos em ordem crescente;  
* elementos em ordem decrescente;  
* elementos em ordem aleatória.

### **2.2 Tamanho dos vetores**

Sugere-se inicialmente utilizar vetores com tamanhos da ordem de:

* 1.000 elementos;  
* 10.000 elementos;  
* 100.000 elementos;  
* 1.000.000 de elementos.  
* …?

Os grupos poderão utilizar tamanhos maiores ou diferentes, desde que os computadores e o tempo disponível permitam a realização dos experimentos.

Para os vetores em ordem crescente e decrescente, poderá ser utilizado apenas um dos maiores tamanhos considerados no experimento, caso isso seja suficiente para a análise.

### **2.3 Comparabilidade das entradas**

Para uma comparação justa entre algoritmos, **todos os algoritmos que participarem de uma determinada configuração experimental deverão receber exatamente os mesmos dados de entrada**.

Como os algoritmos normalmente modificam o vetor durante a ordenação, deverá ser utilizada uma cópia do vetor original para cada execução.

Por exemplo:

`vetor original`  
      `│`  
      `├── cópia → Bubble Sort`  
      `├── cópia → Insertion Sort`  
      `├── cópia → Selection Sort`  
      `├── cópia → ...`  
      `└── cópia → Quick Sort`

Dessa forma, a execução de um algoritmo não altera os dados utilizados pelos demais.

# **4\. Etapa 3 – Medição dos tempos de execução**

Cada grupo deverá preparar um código auxiliar responsável por executar os algoritmos e registrar seus tempos de execução.

A medição deverá considerar **somente o processo de ordenação**, não devendo incluir a geração dos vetores, a criação das cópias, a impressão dos resultados ou outras atividades externas ao algoritmo.

Um esquema simplificado é:

`long inicio = System.nanoTime();`

`sort(vetor);`

`long fim = System.nanoTime();`

`long tempo = fim - inicio;`

Recomenda-se utilizar o método `System.nanoTime()` da API Java para a medição dos intervalos de tempo.

Como a execução ocorre sobre a máquina virtual Java, recomenda-se realizar algumas execuções preliminares antes da coleta dos dados utilizados nos resultados, de modo a reduzir a influência das primeiras execuções da JVM. Esses tempos preliminares não deverão fazer parte dos resultados apresentados.

# **5\. Etapa 4 – Planejamento e execução dos experimentos**

Cada combinação de:

**algoritmo × tamanho do vetor × configuração dos dados**

deverá ser executada várias vezes.

Deverão ser realizadas **pelo menos 10 execuções** de cada configuração, sendo recomendadas **30 ou mais repetições** quando o tempo disponível permitir.

Todos os tempos individuais deverão ser registrados.

Os experimentos deverão procurar manter condições semelhantes entre as diferentes execuções. 

Por exemplo:

* utilizar as mesmas entradas;  
* utilizar cópias equivalentes dos vetores;  
* medir somente o tempo de ordenação;  
* utilizar a mesma configuração de hardware e software;  
* evitar, tanto quanto possível, atividades externas que possam interferir significativamente nas medições.

Não é necessário eliminar completamente todas as fontes de variação existentes em um computador real. Entretanto, o grupo deverá reconhecer que fatores externos podem influenciar os tempos medidos e deverá procurar minimizar seus efeitos.

# **6\. Algoritmos de tempo linear**

Counting Sort, Radix Sort e Bucket Sort deverão ser analisados considerando suas características específicas.

Esses algoritmos não utilizam comparação entre elementos da mesma forma que os demais algoritmos estudados e dependem de determinadas propriedades dos dados de entrada.

Por esse motivo, os grupos deverão descrever as condições utilizadas para esses algoritmos e discutir as implicações dessas condições para os resultados obtidos.

Sempre que for possível estabelecer uma comparação adequada com os demais algoritmos, essa comparação poderá ser realizada. Nesse caso, deverão ser explicitadas as condições que tornam a comparação válida.

A análise deverá considerar que a complexidade assintótica, isoladamente, não determina o tempo de execução observado em uma implementação concreta.

import java.util.Arrays;
import java.util.Vector;

public class BubbleSort <T extends Comparable<T>> extends Ordenador<T> {

    public BubbleSort(){
        super();
    }

    @Override 
    public void sort(){
    
        this.tempoInicial = System.nanoTime();
        if (this.vetor == null) {
            throw new Error("Vetor Vazio!   ");
        }
        if (this.vetor.size() > 1) {
            executarBubbleSort();
        }
        this.tempoFinal = System.nanoTime();
        this.tempoTotal = this.tempoFinal - this.tempoInicial;
    }
    

    @Override 
    public long getTempoTotal(){
        this.tempoTotal = this.tempoFinal - this.tempoInicial;
        return this.tempoTotal;
    }

    private void executarBubbleSort() {
        int n = this.vetor.size();
        boolean trocou;

        for(int i = 0; i < n - 1; i++){
            trocou = false;

            for(int j = 0; j < n - 1 - i; j++){
                if(this.vetor.get(j).compareTo(this.vetor.get(j + 1)) > 0){
                    T temp = this.vetor.get(j);
                    this.vetor.set(j, this.vetor.get(j + 1));
                    this.vetor.set(j + 1, temp);
                    trocou = true;
                }
            }

            if(!trocou){
                break;
            }
        }
    }

    public static void main(String args[]){
        BubbleSort<Integer> bubble = new BubbleSort<>();
        bubble.setVetor(new Vector<>(Arrays.asList(4,2,3,1,5,6,2,3,4,5,2,3,3,4,7,8)));
        bubble.print();
        bubble.sort();
        bubble.print();
    }
}

import java.util.Arrays;
import java.util.Vector;
import java.util.Collections;

public class BucketSort extends Ordenador<Integer> {

    public BucketSort() {
        super();
    }

    @Override
    public void sort() {
        if (this.vetor == null || this.vetor.size() <= 1) {
            return;
        }

        int max = Collections.max(this.vetor);
        int min = Collections.min(this.vetor);

        if (max == min) {
            return;
        }

        int n = this.vetor.size();
        int numBuckets = (int) Math.sqrt(n);
        if (numBuckets < 1) {
            numBuckets = 1;
        }

        @SuppressWarnings("unchecked")
        Vector<Integer>[] buckets = new Vector[numBuckets + 1];
        for (int i = 0; i <= numBuckets; i++) {
            buckets[i] = new Vector<>();
        }

        double range = (double) (max - min + 1);
        for (int i = 0; i < n; i++) {
            int val = this.vetor.get(i);
            int bucketIndex = (int) ((val - min) / range * numBuckets);
            if (bucketIndex > numBuckets) {
                bucketIndex = numBuckets;
            }
            buckets[bucketIndex].add(val);
        }

        int index = 0;
        for (int i = 0; i <= numBuckets; i++) {
            if (!buckets[i].isEmpty()) {
                Collections.sort(buckets[i]);
                for (int val : buckets[i]) {
                    this.vetor.set(index++, val);
                }
            }
        }
    }

    public static void main(String args[]) {
        BucketSort bucket = new BucketSort();
        bucket.setVetor(new Vector<>(Arrays.asList(4, 2, 3, 1, 5, 6, 2, 3, 4, 5, 2, 3, 3, 4, 7, 8)));
        bucket.print();
        bucket.sort();
        bucket.print();
    }
}

import java.util.Random;
import java.util.Arrays;

public class CasosAlgoritmo {

    public static void ordem_crescente(Integer[] v, int n) {
        int limite = Math.min(n, v.length);
        for (int i = 0; i < limite; i++) {
            v[i] = i;
        }
    }

    public static void ordem_decrescente(Integer[] v, int n) {
        int limite = Math.min(n, v.length);
        for (int i = 0; i < limite; i++) {
            v[i] = limite - i; 
        }
    }

    public static void ordem_aleatoria(Integer[] v, int n) {
        Random gerador = new Random();
        int limite = Math.min(n, v.length);

        for (int i = 0; i < limite; i++) {
            v[i] = gerador.nextInt(1000); 
        }
    }

    public static void ordem_repetidas(Integer[] v, int n, int valor) {
        int limite = Math.min(n, v.length);
        Arrays.fill(v, 0, limite, valor);
    }

}

import java.util.Arrays;
import java.util.Vector;
import java.util.Collections;

public class CountingSort extends Ordenador<Integer> {

    public CountingSort() {
        super();
    }

    @Override
    public void sort() {
        if (this.vetor == null || this.vetor.size() <= 1) {
            return;
        }

        int max = Collections.max(this.vetor);
        int min = Collections.min(this.vetor);
        int range = max - min + 1;

        int[] count = new int[range];
        int n = this.vetor.size();

        for (int i = 0; i < n; i++) {
            count[this.vetor.get(i) - min]++;
        }

        int index = 0;
        for (int i = 0; i < range; i++) {
            while (count[i] > 0) {
                this.vetor.set(index++, i + min);
                count[i]--;
            }
        }
    }

    public static void main(String args[]) {
        CountingSort counting = new CountingSort();
        counting.setVetor(new Vector<>(Arrays.asList(4, 2, 3, 1, 5, 6, 2, 3, 4, 5, 2, 3, 3, 4, 7, 8)));
        counting.print();
        counting.sort();
        counting.print();
    }
}

import java.util.Arrays;
import java.util.Vector;

public class HeapSort<T extends Comparable<T>> extends Ordenador<T> {

    public HeapSort() {
        super();
    }

    @Override
    public void sort() {
        if (this.vetor == null || this.vetor.size() <= 1) {
            return;
        }

        int n = this.vetor.size();

        // Constrói o heap (reorganiza o vetor)
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(n, i);
        }

        // Extrai os elementos do heap um a um
        for (int i = n - 1; i > 0; i--) {
            T temp = this.vetor.get(0);
            this.vetor.set(0, this.vetor.get(i));
            this.vetor.set(i, temp);

            heapify(i, 0);
        }
    }

    private void heapify(int n, int i) {
        int maior = i;
        int esquerda = 2 * i + 1;
        int direita = 2 * i + 2;

        if (esquerda < n && this.vetor.get(esquerda).compareTo(this.vetor.get(maior)) > 0) {
            maior = esquerda;
        }

        if (direita < n && this.vetor.get(direita).compareTo(this.vetor.get(maior)) > 0) {
            maior = direita;
        }

        if (maior != i) {
            T troca = this.vetor.get(i);
            this.vetor.set(i, this.vetor.get(maior));
            this.vetor.set(maior, troca);

            heapify(n, maior);
        }
    }

    public static void main(String args[]) {
        HeapSort<Integer> heap = new HeapSort<>();
        heap.setVetor(new Vector<>(Arrays.asList(4, 2, 3, 1, 5, 6, 2, 3, 4, 5, 2, 3, 3, 4, 7, 8)));
        heap.print();
        heap.sort();
        heap.print();
    }
}

import java.util.Arrays;
import java.util.Vector;

public class InsertionSort<T extends Comparable<T>> extends Ordenador<T> {

    public InsertionSort() {
        super();
    }

    @Override 
    public void sort() {
        if (this.vetor == null) return;
        
        int n = this.vetor.size();
        
        for (int i = 1; i < n; i++) {
            T chave = this.vetor.get(i);
            int j = i - 1;

            // Desloca os elementos maiores para a direita utilizando .get() e .set()
            while (j >= 0 && this.vetor.get(j).compareTo(chave) > 0) {
                this.vetor.set(j + 1, this.vetor.get(j));
                j--;
            }
            
            // Insere a chave na sua posição correta
            this.vetor.set(j + 1, chave);
        }
    }

    public static void main(String args[]){
        InsertionSort<Integer> insertion = new InsertionSort<>();
        insertion.setVetor(new Vector<>(Arrays.asList(4,2,3,1,5,6,4,7,8)));
        insertion.print();
        insertion.sort();
        insertion.print();
    }
}

import java.time.LocalTime;
import java.time.format.DateTimeFormatter;
import java.util.Locale;

/**
 * Logger simples para o TP1, inspirado no estilo visual de logs do Node.js.
 * Suporta níveis, contexto, cores ANSI e uma barra de progresso.
 */
public final class Logs {

    private static final DateTimeFormatter HORARIO = DateTimeFormatter.ofPattern("HH:mm:ss");
    private static final int LARGURA_NIVEL = 7;
    private static final int LARGURA_BARRA = 24;

    private static final String RESET = "\u001B[0m";
    private static final String CINZA = "\u001B[90m";
    private static final String AZUL = "\u001B[34m";
    private static final String CIANO = "\u001B[36m";
    private static final String VERDE = "\u001B[32m";
    private static final String AMARELO = "\u001B[33m";
    private static final String VERMELHO = "\u001B[31m";
    private static final String MAGENTA = "\u001B[35m";
    private static final String NEGRITO = "\u001B[1m";

    private static volatile boolean debugAtivado;
    private static volatile boolean coresAtivadas = detectarSuporteACores();

    private Logs() {
        // Classe utilitaria: nao deve ser instanciada.
    }

    /** Ativa ou desativa mensagens de nivel DEBUG. */
    public static void setDebug(boolean ativado) {
        debugAtivado = ativado;
    }

    /** Permite forcar a exibicao ou a remocao das cores ANSI. */
    public static void setCores(boolean ativadas) {
        coresAtivadas = ativadas;
    }

    public static boolean isDebugAtivado() {
        return debugAtivado;
    }

    public static void info(String contexto, String mensagem) {
        escrever("INFO", contexto, mensagem, CIANO);
    }

    public static void success(String contexto, String mensagem) {
        escrever("SUCCESS", contexto, mensagem, VERDE);
    }

    public static void debug(String contexto, String mensagem) {
        if (debugAtivado) {
            escrever("DEBUG", contexto, mensagem, MAGENTA);
        }
    }

    public static void warn(String contexto, String mensagem) {
        escrever("WARN", contexto, mensagem, AMARELO);
    }

    public static void error(String contexto, String mensagem) {
        escrever("ERROR", contexto, mensagem, VERMELHO);
    }

    /** Atalhos usando o contexto padrao "TP1". */
    public static void info(String mensagem) {
        info("TP1", mensagem);
    }

    public static void success(String mensagem) {
        success("TP1", mensagem);
    }

    public static void debug(String mensagem) {
        debug("TP1", mensagem);
    }

    public static void warn(String mensagem) {
        warn("TP1", mensagem);
    }

    public static void error(String mensagem) {
        error("TP1", mensagem);
    }

    /**
     * Registra o progresso atual. A barra e a mensagem so aparecem em modo debug.
     */
    public static void progress(
        String contexto,
        long concluidas,
        long total,
        String decorrido,
        String restante
    ) {
        if (!debugAtivado) {
            return;
        }

        double percentual = total <= 0 ? 100.0 : Math.min(100.0, concluidas * 100.0 / total);
        int preenchidas = (int) Math.round(LARGURA_BARRA * percentual / 100.0);
        StringBuilder barra = new StringBuilder(LARGURA_BARRA);

        for (int i = 0; i < LARGURA_BARRA; i++) {
            barra.append(i < preenchidas ? '#' : '.');
        }

        String mensagem = String.format(
            Locale.ROOT,
            "%s %5.1f%%  %d/%d  decorrido %s  restante ~%s",
            barra,
            percentual,
            concluidas,
            total,
            decorrido,
            restante
        );
        escrever("PROGRESS", contexto, mensagem, AZUL);
    }

    /** Imprime uma linha divisoria para separar etapas do experimento. */
    public static void divider(String contexto, String titulo) {
        String nome = titulo == null ? "" : titulo.trim();
        int largura = 56;
        if (nome.isEmpty()) {
            info(contexto, repetir('-', largura));
            return;
        }

        String texto = " " + nome + " ";
        int espacos = Math.max(2, largura - texto.length());
        int esquerda = espacos / 2;
        int direita = espacos - esquerda;
        info(contexto, repetir('-', esquerda) + texto + repetir('-', direita));
    }

    private static synchronized void escrever(
        String nivel,
        String contexto,
        String mensagem,
        String cor
    ) {
        String horario = LocalTime.now().format(HORARIO);
        String nomeContexto = contexto == null || contexto.trim().isEmpty() ? "TP1" : contexto.trim();
        String texto = mensagem == null ? "" : mensagem;
        String nivelFormatado = String.format(Locale.ROOT, "%-" + LARGURA_NIVEL + "s", nivel);

        String horarioFormatado = colorir("[" + horario + "]", CINZA);
        String nivelColorido = colorir(nivelFormatado, cor + NEGRITO);
        String contextoColorido = colorir("[" + nomeContexto + "]", AZUL + NEGRITO);

        System.out.println(horarioFormatado + " " + nivelColorido + " " + contextoColorido + " " + texto);
    }

    private static String repetir(char caractere, int quantidade) {
        StringBuilder resultado = new StringBuilder(Math.max(0, quantidade));
        for (int i = 0; i < quantidade; i++) {
            resultado.append(caractere);
        }
        return resultado.toString();
    }

    private static String colorir(String texto, String codigo) {
        return coresAtivadas ? codigo + texto + RESET : texto;
    }

    private static boolean detectarSuporteACores() {
        String semCores = System.getenv("NO_COLOR");
        String terminal = System.getenv("TERM");
        return semCores == null && (terminal == null || !"dumb".equalsIgnoreCase(terminal));
    }
}

public class MergeSort <T extends Comparable<T>> extends Ordenador<T> {

    public MergeSort(){
        super();
    }

    @Override 
    public void sort(){
    
        this.tempoInicial = System.nanoTime();
        if (this.vetor == null) {
            throw new Error("Vetor Vazio!");
        }
        if (this.vetor.size() > 1) {
            executarMergeSort(0, this.vetor.size() - 1);
        }
        this.tempoFinal = System.nanoTime();
        this.tempoTotal = this.tempoFinal - this.tempoInicial;
    }

    private void intercalar(int inicio, int meio, int fim) {
        // Cria cópias temporárias das duas sublistas usando a estrutura Vector
        Vector<T> esquerda = new Vector<>(this.vetor.subList(inicio, meio + 1));
        Vector<T> direita = new Vector<>(this.vetor.subList(meio + 1, fim + 1));

        int i = 0; // Índice para a sublista esquerda
        int j = 0; // Índice para a sublista direita
        int k = inicio; // Índice para o vetor principal original

        // Compara os elementos das duas metades e reinsere no vetor principal ordenadamente
        while (i < esquerda.size() && j < direita.size()) {
            if (esquerda.get(i).compareTo(direita.get(j)) <= 0) {
                this.vetor.set(k, esquerda.get(i));
                i++;
            } else {
                this.vetor.set(k, direita.get(j));
                j++;
            }
            k++;
        }

        // Copia os elementos restantes da sublista esquerda, se houver
        while (i < esquerda.size()) {
            this.vetor.set(k, esquerda.get(i));
            i++;
            k++;
        }

        // Copia os elementos restantes da sublista direita, se houver
        while (j < direita.size()) {
            this.vetor.set(k, direita.get(j));
            j++;
            k++;
        }
    }

    private void executarMergeSort(int inicio, int fim) {
        if (inicio < fim) {
            int meio = inicio + (fim - inicio) / 2;

            // Divide recursivamente a metade esquerda e a direita
            executarMergeSort(inicio, meio);
            executarMergeSort(meio + 1, fim);

            // Une as duas metades ordenadas
            intercalar(inicio, meio, fim);
        }
    }

    public static void main(String args[]){
        MergeSort<Integer> merge = new MergeSort<>();
        merge.setVetor(new Vector<>(Arrays.asList(4,2,3,1,5,6,4,7,8)));
        merge.print();
        merge.sort();
        merge.print();
    }
    
}

import java.util.Arrays;
import java.util.Vector;

public class QuickSort<T extends Comparable<T>> extends Ordenador<T> {

    @Override
    public void sort() {
        if (this.vetor == null || this.vetor.size() <= 1) {
            return;
        }
        quicksort(0, this.vetor.size() - 1);
    }

    private void quicksort(int baixo, int alto) {
        if (baixo < alto) {
            int pi = particionar(baixo, alto);
            quicksort(baixo, pi - 1);
            quicksort(pi + 1, alto);
        }
    }

    private int particionar(int baixo, int alto) {
        T pivo = this.vetor.get(alto);
        int i = (baixo - 1);

        for (int j = baixo; j < alto; j++) {
            if (this.vetor.get(j).compareTo(pivo) <= 0) {
                i++;
                trocar(i, j);
            }
        }

        trocar(i + 1, alto);
        return (i + 1);
    }

    private void trocar(int i, int j) {
        T temp = this.vetor.get(i);
        this.vetor.set(i, this.vetor.get(j));
        this.vetor.set(j, temp);
    }

    public static void main(String args[]){
        QuickSort<Integer> quick = new QuickSort<>();
        quick.setVetor(new Vector<>(Arrays.asList(4,2,3,1,5,7,8,-9,6,4,7,8)));
        quick.print();
        quick.sort();
        quick.print();
    }
}

import java.util.Arrays;
import java.util.Vector;

public class RadixSort extends Ordenador<Integer> {

    public RadixSort() {
        super();
    }

    @Override
    public void sort() {
        if (this.vetor == null || this.vetor.size() <= 1) {
            return;
        }

        // n: quantidade de elementos do vetor.
        int n = this.vetor.size();

        /*
         * O Radix Sort LSD trabalha com chaves nao negativas.
         * Deslocamos os valores para preservar a ordem e tambem suportar
         * inteiros negativos, incluindo Integer.MIN_VALUE.
         */
        long[] valores = new long[n];
        long[] auxiliar = new long[n];
        long k = 0;

        for (int i = 0; i < n; i++) {
            valores[i] = (long) this.vetor.get(i) - Integer.MIN_VALUE;
            if (valores[i] > k) {
                k = valores[i];
            }
        }

        // k e a maior chave apos o deslocamento; determina os digitos necessarios.
        for (long exp = 1; k / exp > 0; exp *= 10) {
            int[] contagem = new int[10];

            // Conta quantos valores possuem cada digito nesta posicao.
            for (int i = 0; i < n; i++) {
                int digito = (int) ((valores[i] / exp) % 10);
                contagem[digito]++;
            }

            // Converte as contagens em posicoes finais cumulativas.
            for (int i = 1; i < contagem.length; i++) {
                contagem[i] += contagem[i - 1];
            }

            // Percorrer de tras para frente preserva a estabilidade da passagem.
            for (int i = n - 1; i >= 0; i--) {
                int digito = (int) ((valores[i] / exp) % 10);
                auxiliar[--contagem[digito]] = valores[i];
            }

            // Alterna os vetores de trabalho para a proxima passagem.
            long[] troca = valores;
            valores = auxiliar;
            auxiliar = troca;
        }

        // Retorna as chaves ao intervalo original e grava o resultado no Vector.
        for (int i = 0; i < n; i++) {
            this.vetor.set(i, (int) (valores[i] + Integer.MIN_VALUE));
        }
    }

    public static void main(String[] args) {
        RadixSort radix = new RadixSort();
        radix.setVetor(new Vector<>(Arrays.asList(42, 7, 315, 89, 7, 0, -12, -315,
                Integer.MIN_VALUE, Integer.MAX_VALUE)));

        radix.print();
        radix.sort();
        radix.print();
    }
}

# TesteGenerator — CLI do TP1 de ACD

`TesteGenerator.java` oferece uma interface de linha de comando (CLI), sem perguntas interativas. Todos os parâmetros são informados como argumentos, então o programa pode ser executado diretamente pelo shell, por scripts `.sh`, cron ou outros automatizadores.

## Requisitos

- JDK instalado (`java` e `javac` disponíveis no `PATH`).
- `TesteGenerator.java`, `Logs.java`, `Ordenador.java`, `CasosAlgoritmo.java` e as classes dos algoritmos na mesma pasta `src`.
- O script `executar_testes.sh` deve ter permissão de execução.

## Uso básico

```bash
chmod +x executar_testes.sh
./executar_testes.sh \
  --repeticoes 10 \
  --caso MEDIO \
  --algoritmo InsertionSort \
  --disposicao ALEATORIO \
  --n 1000 \
  --saida resultados/tp1 \
  --debug
```

A execução não lê nada de `stdin` e não exige confirmação do usuário. O script compila os arquivos Java e encaminha todos os argumentos para `TesteGenerator`.

Se nenhum argumento for fornecido, o script exibe a ajuda em vez de entrar num modo interativo:

```bash
./executar_testes.sh --help
```

## Parâmetros obrigatórios

| Parâmetro | Valores | Significado |
|---|---|---|
| `--repeticoes` | `1` a `1000` | Número de medições oficiais depois dos aquecimentos. |
| `--caso` | `MELHOR`, `PIOR`, `MEDIO` | Rótulo do caso teórico que será registrado no CSV. |
| `--algoritmo` | Nome de um dos dez algoritmos | Algoritmo executado nesta chamada. |
| `--disposicao` | `CRESCENTE`, `DECRESCENTE`, `ALEATORIO`, `REPETIDOS` | Como o vetor de entrada será gerado. |
| `--n` | `1` a `1000000` | Número de elementos do vetor. |

Algoritmos aceitos: `BubbleSort`, `InsertionSort`, `SelectionSort`, `ShellSort`, `HeapSort`, `MergeSort`, `QuickSort`, `CountingSort`, `RadixSort` e `BucketSort`. Os nomes também aceitam abreviações sem o sufixo `Sort`, por exemplo `--algoritmo Radix`.

## Parâmetros opcionais

| Parâmetro | Efeito |
|---|---|
| `--saida PREFIXO` | Pasta/prefixo dos arquivos gerados. Padrão: `resultados_tp1`. |
| `--debug` | Ativa logs detalhados e progresso percentual com estimativa de tempo restante. |
| `--no-color` | Desativa as cores ANSI nos logs. |
| `--help` ou `-h` | Exibe a ajuda e termina. |

## CSV gerado

O nome segue o padrão:

```text
<PREFIXO>_<Algoritmo>_n<TAMANHO>.csv
```

Por exemplo, usando `--saida resultados/tp1`, algoritmo `InsertionSort` e `n=1000`:

```text
resultados/tp1_InsertionSort_n1000.csv
```

O cabeçalho é:

```csv
algoritmo,n,caso,disposicao,sessao,repeticao,t_ns
```

| Coluna | Interpretação |
|---|---|
| `algoritmo` | Algoritmo que foi executado. |
| `n` | Número de elementos no vetor. |
| `caso` | Rótulo experimental solicitado (`MELHOR`, `PIOR` ou `MEDIO`). |
| `disposicao` | Disposição usada para gerar a entrada. |
| `sessao` | Identificador único da execução do programa, para distinguir execuções acumuladas. |
| `repeticao` | Número da medição oficial dentro daquela sessão, de 1 até o valor de `--repeticoes`. |
| `t_ns` | Tempo da chamada `sort()`, em nanossegundos. |

Se o CSV já existir e tiver o cabeçalho esperado, as medições serão acrescentadas ao final. O conteúdo anterior é preservado. Se o cabeçalho for incompatível, a execução falha para evitar misturar formatos diferentes.

## Automatização com shell

### Exemplo: executar um algoritmo por vez

```bash
./executar_testes.sh --repeticoes 10 --caso PIOR \
  --algoritmo InsertionSort --disposicao DECRESCENTE --n 1000 \
  --saida resultados/tp1 --debug
```

### Exemplo: executar várias configurações em sequência

O shell pode percorrer uma lista de tamanhos e algoritmos sem interação. Compile uma vez e chame a classe Java diretamente dentro do loop para evitar recompilar a cada configuração:

```bash
javac -encoding UTF-8 *.java

for algoritmo in MergeSort QuickSort CountingSort RadixSort BucketSort; do
  for n in 1000 10000 100000; do
    java -Xms128m -Xmx1g TesteGenerator \
      --repeticoes 10 \
      --caso MEDIO \
      --algoritmo "$algoritmo" \
      --disposicao ALEATORIO \
      --n "$n" \
      --saida resultados/tp1 \
      --no-color
  done
done
```

O exemplo usa algoritmos adequados, em geral, para vetores maiores. Ao criar loops mais abrangentes, respeite os limites específicos descritos abaixo e confira o código de cada implementação. O `set -e` pode ser usado em um script batch para interromper a execução se algum experimento falhar.

## Aquecimento e medição

O programa executa duas passagens de aquecimento, que não são registradas no CSV. A geração dos dados e a cópia do vetor ficam fora do intervalo cronometrado. A coluna `t_ns` mede apenas a chamada `sort()`.

O progresso e o ETA são estimativas. Os tempos podem variar quando o programa troca de tamanho do vetor ou por causa de atividade externa na máquina.

## Limites preventivos de execução

Para reduzir riscos de execuções demoradas ou falha por recursão/memória:

- `n` máximo: `1.000.000`.
- `BubbleSort`, `InsertionSort` e `SelectionSort`: `n <= 10.000`.
- `QuickSort`: `n <= 100.000`; com disposição crescente ou decrescente, `n <= 1.000`, porque certas estratégias de pivô podem degenerar para `O(n²)` e aprofundar demais a recursão.
- Para algoritmos quadráticos, configurações com `n >= 5.000` aceitam no máximo 10 repetições.
- O script usa por padrão `-Xms128m -Xmx1g`; é possível ajustar a heap:

```bash
JAVA_OPTS='-Xms64m -Xmx512m' ./executar_testes.sh \
  --repeticoes 10 --caso MEDIO --algoritmo RadixSort \
  --disposicao ALEATORIO --n 100000 --saida resultados/tp1
```

Aumentar a heap não resolve complexidade quadrática nem garante que um Quick Sort recursivo evite `StackOverflowError`.

## Importante para o relatório

`caso` e `disposicao` são registrados separadamente. Escolher `--caso MELHOR` não transforma a entrada em melhor caso automaticamente: a relação entre o rótulo e a disposição depende do algoritmo e da implementação. Registre e justifique essa correspondência na metodologia do TP1.

import java.util.Arrays;
import java.util.Vector;

public class SelectionSort<T extends Comparable<T>> extends Ordenador<T> {

    public SelectionSort() {
        super();
    }

    @Override
    public void sort() {
        if (this.vetor == null || this.vetor.size() <= 1) {
            return;
        }

        int n = this.vetor.size();

        for (int i = 0; i < n - 1; i++) {
            int minIndex = i;

            for (int j = i + 1; j < n; j++) {
                if (this.vetor.get(j).compareTo(this.vetor.get(minIndex)) < 0) {
                    minIndex = j;
                }
            }

            if (minIndex != i) {
                T temp = this.vetor.get(i);
                this.vetor.set(i, this.vetor.get(minIndex));
                this.vetor.set(minIndex, temp);
            }
        }
    }

    public static void main(String args[]) {
        SelectionSort<Integer> selection = new SelectionSort<>();
        selection.setVetor(new Vector<>(Arrays.asList(4, 2, 3, 1, 5, 6, 2, 3, 4, 5, 2, 3, 3, 4, 7, 8)));
        selection.print();
        selection.sort();
        selection.print();
    }
}

import java.util.Arrays;
import java.util.Vector;

public class ShellSort<T extends Comparable<T>> extends Ordenador<T> {

    public ShellSort() {
        super();
    }

    @Override 
    public void sort() {
        if (vetor == null) return;
        
        int n = vetor.size();

        // Inicia com um intervalo (gap) grande e vai dividindo por 2 a cada passo
        for (int gap = n / 2; gap > 0; gap /= 2) {
            
            // Aplicação do Insertion Sort para o gap atual
            for (int i = gap; i < n; i++) {
                T temp = vetor.get(i);
                int j = i;

                // Desloca os elementos do sub-vetor até encontrar a posição correta da chave
                while (j >= gap && vetor.get(j - gap).compareTo(temp) > 0) {
                    vetor.set(j, vetor.get(j - gap));
                    j -= gap;
                }
                
                // Insere o elemento na posição correta do gap
                vetor.set(j, temp);
            }
        }
    }

    public static void main(String args[]){
        ShellSort<Integer> shell = new ShellSort<>();
        shell.setVetor(new Vector<>(Arrays.asList(4,2,3,1,5,7,8,-9,6,4,7,8)));
        shell.print();
        shell.sort();
        shell.print();
    }
}

        final int valor;
        try {
            valor = Integer.parseInt(valorTexto);
        } catch (NumberFormatException e) {
            throw new IllegalArgumentException("--" + chave + " deve ser um numero inteiro: " + valorTexto);
        }
        if (valor < minimo || valor > maximo) {
            throw new IllegalArgumentException("--" + chave + " deve estar entre " + minimo + " e " + maximo + ".");
        }
        return valor;
    }

    private static String normalizarAlgoritmo(String valor) {
        String informado = limparIdentificador(valor);
        for (String algoritmo : ALGORITMOS) {
            if (limparIdentificador(algoritmo).equals(informado)) {
                return algoritmo;
            }
        }
        String[] apelidos = {"bubble", "insertion", "selection", "shell", "heap", "merge", "quick", "counting", "radix", "bucket"};
        for (int i = 0; i < apelidos.length; i++) {
            if (apelidos[i].equals(informado)) {
                return ALGORITMOS[i];
            }
        }
        throw new IllegalArgumentException("Algoritmo invalido: " + valor + ". Use --help para ver as opcoes.");
    }

    private static String limparIdentificador(String valor) {
        return valor.toLowerCase(Locale.ROOT).replaceAll("[^a-z0-9]", "");
    }

    private static String normalizarCaso(String valor) {
        String caso = valor.trim().toUpperCase(Locale.ROOT);
        if ("MEDIO".equals(caso) || "MÉDIO".equals(caso) || "MEDIOCASO".equals(caso)) {
            return "MEDIO";
        }
        if ("MELHOR".equals(caso) || "MELHORCASO".equals(caso)) {
            return "MELHOR";
        }
        if ("PIOR".equals(caso) || "PIORCASO".equals(caso)) {
            return "PIOR";
        }
        throw new IllegalArgumentException("Caso invalido: " + valor + ". Valores aceitos: MELHOR, PIOR, MEDIO.");
    }

    private static String normalizarDisposicao(String valor) {
        String disposicao = limparIdentificador(valor);
        switch (disposicao) {
            case "crescente":
                return "CRESCENTE";
            case "decrescente":
                return "DECRESCENTE";
            case "aleatorio":
                return "ALEATORIO";
            case "repetidos":
            case "valoresrepetidos":
                return "REPETIDOS";
            default:
                throw new IllegalArgumentException("Disposicao invalida: " + valor
                    + ". Valores aceitos: CRESCENTE, DECRESCENTE, ALEATORIO, REPETIDOS.");
        }
    }

    private void executar() throws IOException {
        prepararCsv(caminhoCsv);
        inicioExperimentoNs = System.nanoTime();
        repeticoesConcluidas = 0;

        Logs.divider(CONTEXTO, "Preparacao dos dados");
        Vector<Integer> original = gerarVetor(n, disposicao);
        Logs.success(CONTEXTO, "Vetor gerado: n=" + n + ", disposicao=" + disposicao);

        Logs.divider(CONTEXTO, "Aquecimento da JVM");
        for (int i = 1; i <= AQUECIMENTOS; i++) {
            Ordenador<Integer> ordenador = criarOrdenador(algoritmo);
            ordenador.setVetor(new Vector<>(original));
            Logs.debug(CONTEXTO, "Aquecimento " + i + "/" + AQUECIMENTOS + " - " + algoritmo);
            ordenador.sort();
        }

        Logs.divider(CONTEXTO, "Medicoes");
        for (int repeticao = 1; repeticao <= repeticoes; repeticao++) {
            Ordenador<Integer> ordenador = criarOrdenador(algoritmo);
            ordenador.setVetor(new Vector<>(original)); // copia fora do cronometro

            Logs.debug(CONTEXTO, "Iniciando " + algoritmo + " | n=" + n
                + " | caso=" + caso + " | disposicao=" + disposicao
                + " | repeticao=" + repeticao + "/" + repeticoes);

            long inicio = System.nanoTime();
            ordenador.sort();
            long tempoNs = System.nanoTime() - inicio;

            registrarResultado(repeticao, tempoNs);
            repeticoesConcluidas++;

            long decorridoMs = (System.nanoTime() - inicioExperimentoNs) / 1_000_000L;
            Logs.debug(CONTEXTO, "Concluido " + algoritmo + " | sort=" + tempoNs
                + " ns | repeticao=" + repeticao + "/" + repeticoes
                + " | CSV=" + caminhoCsv.getFileName());
            Logs.progress(CONTEXTO, repeticoesConcluidas, repeticoes,
                formatarDuracao(decorridoMs), estimarRestante(decorridoMs, repeticoesConcluidas, repeticoes));
        }

        long totalMs = (System.nanoTime() - inicioExperimentoNs) / 1_000_000L;
        Logs.divider(CONTEXTO, "Resumo");
        Logs.success(CONTEXTO, "Experimento finalizado.");
        Logs.info(CONTEXTO, "Medicoes gravadas nesta execucao: " + repeticoesConcluidas);
        Logs.info(CONTEXTO, "Tempo total (inclui preparacao e aquecimentos): " + formatarDuracao(totalMs));
        Logs.info(CONTEXTO, "CSV: " + caminhoCsv.toAbsolutePath());
    }

    private void registrarResultado(int repeticao, long tempoNs) throws IOException {
        try (BufferedWriter escritor = Files.newBufferedWriter(
                caminhoCsv,
                StandardOpenOption.CREATE,
                StandardOpenOption.WRITE,
                StandardOpenOption.APPEND)) {
            escritor.write(algoritmo + "," + n + "," + caso + "," + disposicao + ","
                + sessao + "," + repeticao + "," + tempoNs);
            escritor.newLine();
        }
    }

    private static void prepararCsv(Path caminho) throws IOException {
        Path pasta = caminho.toAbsolutePath().getParent();
        if (pasta != null) {
            Files.createDirectories(pasta);
        }
        if (Files.exists(caminho) && Files.size(caminho) > 0) {
            try (BufferedReader leitor = Files.newBufferedReader(caminho)) {
                String cabecalhoExistente = leitor.readLine();
                if (!CABECALHO_CSV.equals(cabecalhoExistente)) {
                    throw new IOException("Cabecalho CSV incompatível em " + caminho
                        + ". Esperado: " + CABECALHO_CSV + ". Use outro --saida para evitar misturar formatos.");
                }
            }
        } else {
            try (BufferedWriter escritor = Files.newBufferedWriter(
                    caminho, StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING,
                    StandardOpenOption.WRITE)) {
                escritor.write(CABECALHO_CSV);
                escritor.newLine();
            }
        }
    }

    private static Vector<Integer> gerarVetor(int n, String disposicao) {
        Integer[] dados = new Integer[n];
        switch (disposicao) {
            case "CRESCENTE":
                CasosAlgoritmo.ordem_crescente(dados, n);
                break;
            case "DECRESCENTE":
                CasosAlgoritmo.ordem_decrescente(dados, n);
                break;
            case "ALEATORIO":
                CasosAlgoritmo.ordem_aleatoria(dados, n);
                break;
            case "REPETIDOS":
                CasosAlgoritmo.ordem_repetidas(dados, n, 5);
                break;
            default:
                throw new IllegalArgumentException("Disposicao desconhecida: " + disposicao);
        }
        return new Vector<>(Arrays.asList(dados));
    }

    private static Ordenador<Integer> criarOrdenador(String algoritmo) {
        switch (algoritmo) {
            case "BubbleSort": return new BubbleSort<>();
            case "InsertionSort": return new InsertionSort<>();
            case "SelectionSort": return new SelectionSort<>();
            case "ShellSort": return new ShellSort<>();
            case "HeapSort": return new HeapSort<>();
            case "MergeSort": return new MergeSort<>();
            case "QuickSort": return new QuickSort<>();
            case "CountingSort": return new CountingSort();
            case "RadixSort": return new RadixSort();
            case "BucketSort": return new BucketSort();
            default: throw new IllegalArgumentException("Algoritmo nao reconhecido: " + algoritmo);
        }
    }

    private static boolean validarLimites(String algoritmo, String disposicao, int n, int repeticoes) {
        if (n > MAX_N) {
            Logs.error(CONTEXTO, "Limite maximo de n: " + MAX_N + ".");
            return false;
        }
        if (isQuadratico(algoritmo) && n > 10_000) {
            Logs.error(CONTEXTO, algoritmo + " limitado a n <= 10000 para reduzir execucoes quadraticas excessivas.");
            return false;
        }
        if ("QuickSort".equals(algoritmo) && n > 100_000) {
            Logs.error(CONTEXTO, "QuickSort limitado a n <= 100000 por risco de degradacao/recursao.");
            return false;
        }
        if ("QuickSort".equals(algoritmo)
            && ("CRESCENTE".equals(disposicao) || "DECRESCENTE".equals(disposicao))
            && n > 1_000) {
            Logs.error(CONTEXTO, "QuickSort com disposicao crescente/decrescente limitado a n <= 1000.");
            return false;
        }
        if (isQuadratico(algoritmo) && n >= 5_000 && repeticoes > 10) {
            Logs.error(CONTEXTO, "Configuracao conservadora: algoritmo quadratico com n >= 5000 aceita no maximo 10 repeticoes.");
            return false;
        }
        if (n >= 100_000) {
            Logs.warn(CONTEXTO, "n elevado: consumo de memoria/tempo depende da implementacao e da heap da JVM.");
        }
        return true;
    }

    private static boolean isQuadratico(String algoritmo) {
        return "BubbleSort".equals(algoritmo)
            || "InsertionSort".equals(algoritmo)
            || "SelectionSort".equals(algoritmo);
    }

    private static void avisarSobreCaso(String algoritmo, String caso, String disposicao) {
        if (("BubbleSort".equals(algoritmo) || "InsertionSort".equals(algoritmo))) {
            String esperada = "MELHOR".equals(caso) ? "CRESCENTE"
                : ("PIOR".equals(caso) ? "DECRESCENTE" : "ALEATORIO");
            if (!esperada.equals(disposicao)) {
                Logs.warn(CONTEXTO, "Para " + algoritmo + ", a disposicao normalmente associada ao caso "
                    + caso + " e " + esperada + "; a configuracao solicitada sera registrada mesmo assim.");
            }
        }
        Logs.info(CONTEXTO, "caso e disposicao sao registrados separadamente; a disposicao nao define automaticamente o caso teorico para todos os algoritmos.");
    }

    private static Path criarCaminhoCsv(String prefixoInformado, String algoritmo, int n) {
        String prefixo = prefixoInformado.trim();
        if (prefixo.toLowerCase(Locale.ROOT).endsWith(".csv")) {
            prefixo = prefixo.substring(0, prefixo.length() - 4);
        }
        if (prefixo.isEmpty()) {
            prefixo = "resultados_tp1";
        }
        Path caminhoPrefixo = Paths.get(prefixo).toAbsolutePath();
        Path pasta = caminhoPrefixo.getParent();
        String nomePrefixo = caminhoPrefixo.getFileName() == null
            ? "resultados_tp1" : caminhoPrefixo.getFileName().toString();
        String nomeArquivo = nomePrefixo + "_" + algoritmo + "_n" + n + ".csv";
        return pasta == null ? Paths.get(nomeArquivo) : pasta.resolve(nomeArquivo);
    }

    private static String estimarRestante(long decorridoMs, int concluidas, int total) {
        if (concluidas <= 0) return "calculando...";
        if (concluidas >= total) return "00:00:00";
        double mediaMs = decorridoMs / (double) concluidas;
        long restanteMs = Math.max(0L, (long) (mediaMs * (total - concluidas)));
        return formatarDuracao(restanteMs);
    }

    private static String formatarDuracao(long milissegundos) {
        long segundos = Math.max(0L, milissegundos) / 1000L;
        long horas = segundos / 3600L;
        long minutos = (segundos % 3600L) / 60L;
        long segundosRestantes = segundos % 60L;
        return String.format(Locale.ROOT, "%02d:%02d:%02d", horas, minutos, segundosRestantes);
    }
